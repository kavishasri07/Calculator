# Calculator
A simple, responsive calculator built using **HTML**, **CSS**, and vanilla **JavaScript**. It performs basic arithmetic operations with a clean, minimal UI.

## Features
- Addition, subtraction, multiplication, and division
- Decimal number support
- Clear (C) button to reset the display
- Built entirely with vanilla JS — no frameworks or libraries

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6)
